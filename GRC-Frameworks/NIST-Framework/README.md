## NIST Cybersecurity Framework

The NIST Cybersecurity Framework (CSF) provides organisations with a structured approach to identifying, assessing and managing cybersecurity risks.

The six core functions of NIST CSF 2.0 are:

| Function | Purpose |
|---|---|
| Govern | Establish cybersecurity risk management strategy, policies and responsibilities |
| Identify | Understand critical assets, systems, vulnerabilities and risks |
| Protect | Implement safeguards such as MFA, access controls and encryption |
| Detect | Identify suspicious activity and potential cybersecurity incidents |
| Respond | Manage, contain and communicate security incidents |
| Recover | Restore affected systems and improve organisational resilience |

## Practical Training Scenarios

### 1. Banking — Mobile Banking Application

**Scenario:** Assess cybersecurity risks affecting a mobile banking platform.

Key areas explored:
- Customer account and transaction security
- Authentication weaknesses and password reuse
- API security and SQL injection risks
- Cloud infrastructure misconfigurations
- Recommended security controls and risk mitigation

### 2. Healthcare — Electronic Medical Records (EMR)

**Scenario:** Apply NIST security principles to a healthcare environment handling sensitive patient information.

Key areas explored:
- Protection of electronic medical records
- Access control weaknesses
- Encryption and network segmentation
- Healthcare data privacy and HIPAA considerations
- Security monitoring and incident response

### 3. Insurance — Digital Claims Processing Platform

**Scenario:** Assess risks affecting an online insurance claims system.

Key areas explored:
- Insecure document uploads
- Unpatched databases
- API input validation weaknesses
- Web application protection
- Risk identification and security improvement recommendations

### 4. Government — Citizen Services Portal

**Scenario:** Apply NIST cybersecurity principles to an online government services platform.

Key areas explored:
- Protection of citizen information
- Session management weaknesses
- Excessive user privileges
- API security vulnerabilities
- Availability and resilience of public services

### 5. Superannuation — MFA Security Breach

**Scenario:** Review a cybersecurity breach involving inadequate multi-factor authentication controls.

Key areas explored:
- Identity and access management
- Authentication security gaps
- Customer account protection
- Risk identification and control recommendations
- Incident response and recovery considerations
